# ScooterLink

A lightweight installable web-app preview for iPhone.

## Install
1. Enable GitHub Pages for this repository using **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
2. Wait for GitHub Pages to publish the site.
3. Open the published HTTPS address in Safari on the iPhone.
4. Tap **Share → Add to Home Screen**.

## Important hardware limitations
This repository currently provides an installable interface preview only. It does not yet connect to the Temu glasses, mirror the iPhone display, route audio, or read glasses battery status. iOS Safari does not expose Web Bluetooth. Actual device support requires identifying the glasses' Bluetooth profiles/protocol and may require a native iOS app or a compatible manufacturer integration.

No hardware capability should be considered working until tested with the exact glasses.
