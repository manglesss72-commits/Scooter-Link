# ScooterLink VR

An installable iPhone-first VR-style dashboard preview for smart glasses.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
3. Wait for GitHub Pages to publish.
4. Open the HTTPS Pages URL in Safari on iPhone.
5. Tap **Share → Add to Home Screen**.

## What this version does
- Presents a responsive VR-inspired home screen.
- Provides links to Roblox, Minecraft information, Fortnite mobile availability, and video services.
- Shows connection/display compatibility guidance.
- Offers interface-only display quality, motion, and audio preferences.
- Caches the app shell for offline reopening after the first successful load.

## What it does NOT do
- It does not mirror the iPhone screen to glasses.
- It does not stream games, convert mobile games into VR, or create official VR modes for Roblox, Minecraft, or Fortnite.
- It does not connect to the Temu glasses, read their battery, or route audio directly.
- It does not measure FPS, temperature, or display latency.

## Hardware and performance requirements
The previously shared Temu AI glasses listing did not establish that the glasses contain a video display or accept USB-C DisplayPort/HDMI input. Bluetooth alone cannot carry a smooth video feed. For a low-latency display path, the glasses must explicitly support a video input compatible with the exact iPhone model (for example, USB-C DisplayPort Alt Mode). iPhone 16/17 model variants differ, so verify the exact model and glasses specifications before buying adapters.

A native iOS app or manufacturer-supported integration may be needed for hardware features. No compatibility or lag-free performance claim should be made until tested on the actual devices.
